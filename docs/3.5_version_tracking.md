# 3.5版本新增埋点实现文档

## 概述

本文档记录了3.5版本新增的7个埋点事件，用于追踪用户在定位、足迹、用机记录页面的蒙版按钮点击行为，以及绑定弹窗挽回弹窗的按钮点击行为。

## 埋点列表

### 1. 定位-立刻去绑定 (location3.5_tobind)

**事件ID**: `location3.5_tobind`

**参数**:
- `device_id`: 虚拟用户ID（通过用户设备号生成）
- `user_id`: 用户ID（已登录时）
- `click_time`: 点击时间（格式：年/月/日 时:分:秒）

**触发场景**:
1. 定位页面蒙版上的"立刻去绑定"按钮点击（未绑定状态）

**代码位置**:
- 埋点方法: `lib/services/tracking_service.dart` - `TrackingService.trackLocationToBind()`

### 7. 绑定页面挽回弹窗 (home3.5_tobind_reback)

**事件ID**: `home3.5_tobind_reback`

**参数**:
- `device_id`: 虚拟用户ID（通过用户设备号生成）
- `user_id`: 用户ID（已登录时）
- `click_time`: 点击时间（格式：年/月/日 时:分:秒）
- `button_name`: 点击按钮名称（"再想想"或"立即绑定"）

**触发场景**:
**⚠️ 重要：此埋点仅针对首页的绑定弹窗**

用户在**任意页面**的绑定弹窗点击关闭按钮时，都会弹出挽回弹窗，用户点击挽回弹窗中的任一按钮时：
- 点击"再想想"按钮：关闭绑定弹窗
- 点击"立即绑定"按钮：继续绑定流程

**说明**:
- **全局实现**：所有页面的绑定弹窗点击关闭按钮时都会弹出挽回弹窗
- **全局禁用滑动和背景点击**：所有绑定弹窗已禁止通过滑动或点击背景关闭
- **埋点仅针对首页**：只有首页的绑定弹窗会上报埋点，其他页面不会
- **通过 `caller` 参数判断**：`CustomBottomDialog` 根据 `caller == BindingDialogCaller.home` 判断是否来自首页

**代码位置**:
- 埋点方法: `lib/services/tracking_service.dart` - `TrackingService.trackBindingReback()`
- 挽回弹窗组件: `lib/widgets/dialogs/binding_close_confirm_dialog.dart`
  - "再想想"按钮点击（line 61-62）
  - "立即绑定"按钮点击（line 95-96）
- 全局实现: `lib/widgets/dialogs/custom_bottom_dialog.dart`
  - 关闭按钮统一调用挽回弹窗（line 75-99）
  - 全局禁用滑动和背景点击关闭（line 403-404）
  - 根据 `caller` 参数判断是否上报埋点（line 80）

## 实现细节

### 埋点服务方法

所有埋点方法都遵循统一的实现模式：

```dart
/// 埋点：[页面名称]-[操作名称]
/// 
/// 事件ID: [event_id]
/// 
/// 参数：
/// - device_id: 虚拟用户ID
/// - user_id: 用户ID
/// - click_time: 点击时间
/// 
/// 触发场景：[具体触发场景描述]
static Future<void> trackXxx() async {
  final params = await _buildBaseParams();
  await _trackEvent('[event_id]', params, '[事件名称]');
}
```

### 基础参数构建

所有埋点使用 `_buildBaseParams()` 方法构建基础参数，该方法会自动获取：
- `device_id`: 从友盟获取或创建的虚拟用户ID
- `user_id`: 当前登录用户的ID（如果已登录）
- `click_time`: 当前时间（格式化为：年/月/日 时:分:秒）

### 调用方式

在各个页面的按钮点击事件中，使用 `async/await` 方式调用埋点方法：

```dart
// 示例：定位页面蒙版按钮点击
GestureDetector(
  onTap: () async {
    if (!isBindPartner) {
      // 上报埋点：定位-立刻去绑定
      await TrackingService.trackLocationToBind();
      widget.controller.performBindAction();
    } else {
      // 上报埋点：定位-立刻开通会员
      await TrackingService.trackLocationToVip();
      widget.controller.onOpenMembershipButtonTap();
    }
  },
  child: ...,
)
```

2. **足迹页面测试**
   - 未绑定状态：点击蒙版上的"立刻去绑定"按钮，验证 `track3.5_tobind` 埋点
   - 已绑定未开会员状态：点击蒙版上的"立刻开通会员"按钮，验证 `track3.5_tovip` 埋点

3. **用机记录页面测试**
   - 未绑定状态：点击蒙版上的"立刻去绑定"按钮，验证 `history3.5_tobind` 埋点
   - 已绑定未开会员状态：点击蒙版上的"立刻开通会员"按钮，验证 `history3.5_vip` 埋点

4. **绑定弹窗挽回测试**
   - **任意页面**打开绑定弹窗后点击关闭按钮，都会弹出挽回弹窗
   - **验证全局禁用**：尝试滑动关闭或点击背景，应该无法关闭绑定弹窗
   - **从首页测试埋点**：
     - 从首页打开绑定弹窗，点击关闭按钮，弹出挽回弹窗

     - 点击"立即绑定"按钮，验证 `home3.5_tobind_reback` 埋点（button_name="立即绑定"）

## 注意事项

1. 所有埋点都使用 `async/await` 方式调用，确保埋点上报后再执行后续操作
2. 埋点方法中已经包含异常处理，不会影响正常业务流程
3. 埋点参数中的 `click_time` 格式必须为：`年/月/日 时:分:秒`（例如：`2025/10/30 14:30:45`）
4. `user_id` 参数仅在用户已登录时包含，未登录时该字段为空字符串或不包含在参数中
5. **绑定弹窗全局限制**：
   - 所有绑定弹窗已全局禁用滑动关闭和背景点击关闭
   - 只能通过点击关闭按钮触发挽回弹窗
   - 在挽回弹窗中点击"再想想"才能真正关闭绑定弹窗
6. **绑定页面挽回弹窗埋点（`home3.5_tobind_reback`）仅针对首页的绑定弹窗**，通过 `caller` 参数判断，其他页面的绑定弹窗虽然也会弹出挽回弹窗，但不会触发埋点
