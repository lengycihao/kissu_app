# 轨迹页面默认展示另一半数据功能

## 概述

实现了默认展示另一半数据的功能：正常进入轨迹页面时（不带任何点位信息），默认展示另一半当天的数据。

## 实现日期

2025-10-22

## 修改文件

### `lib/pages/track/managers/track_data_manager.dart`

**修改点：** 修改默认用户类型

```dart
/// 当前显示的是哪个用户（1=自己，0=另一半）
/// 🎯 默认显示另一半的数据
final currentUserType = 0.obs;  // 从 1 改为 0
```

**说明：**
- 原来默认值是 `1`（自己）
- 现在默认值是 `0`（另一半）
- 这样正常进入轨迹页面时，会自动展示另一半的数据

---

## 功能说明

### 场景 1：正常进入轨迹页面

**触发条件：** 用户直接点击导航栏的"轨迹"按钮进入

**行为：**
1. 轨迹页面初始化
2. `TrackDataManager` 的 `currentUserType` 默认值为 `0`（另一半）
3. 数据加载时并行获取自己和另一半的数据
4. 由于 `currentUserType = 0`，默认展示另一半的轨迹数据
5. 地图、标记、统计都显示另一半的数据

**结果：** 默认看到另一半的轨迹

---

### 场景 2：从定位页面点击停留点进入

**触发条件：** 用户在定位页面点击某个停留点记录，跳转到轨迹页面

**行为：**
1. 轨迹页面初始化，带有初始坐标信息
2. 数据加载时并行获取自己和另一半的数据
3. **由于 `currentUserType` 默认为 `0`（另一半）**
4. 如果点击的是自己的停留点，需要用户手动切换到自己的头像
5. 如果点击的是另一半的停留点，无需切换，直接显示

**结果：** 
- 点击另一半的停留点 → 直接显示（无需切换）
- 点击自己的停留点 → 需要手动切换头像

---

## 数据流程

### 正常进入流程

```
用户点击"轨迹"
    ↓
TrackController.onInit()
    ↓
currentUserType = 0 (另一半)
    ↓
加载两个用户数据
    ↓
展示另一半的轨迹
```

### 带点位进入流程

```
用户点击定位页面的停留点
    ↓
跳转到轨迹页面，传递坐标 (lat, lng)
    ↓
TrackController.setInitialCoordinates()
    ↓
currentUserType = 0 (另一半)
    ↓
加载两个用户数据
    ↓
展示另一半的轨迹
    ↓
如果需要查看自己的停留点，用户手动切换头像
```

## 测试建议

### 测试用例 1：正常进入

1. 直接点击底部导航栏的"轨迹"按钮
2. 检查页面顶部的头像，应该默认选中另一半的头像
3. 检查地图上的轨迹和停留点，应该是另一半的数据

### 测试用例 2：点击另一半的停留点

1. 在定位页面，切换到另一半的头像
2. 点击列表中的某个停留点
3. 跳转到轨迹页面后，检查头像应该保持在另一半
4. 检查地图上的轨迹和停留点，应该是另一半的数据
5. 检查是否有高亮的圆圈标记点击的停留点

### 测试用例 3：点击自己的停留点

1. 在定位页面，确认当前查看的是自己的数据
2. 点击列表中的某个停留点
3. 跳转到轨迹页面后，会显示另一半的数据（因为默认）
4. 用户需要手动点击自己的头像切换
5. 切换后检查地图上的轨迹和停留点，应该是自己的数据
6. 检查是否有高亮的圆圈标记点击的停留点

## 注意事项

1. **默认用户变更：** 由于改变了默认显示的用户，可能影响用户习惯
2. **点击自己的停留点：** 从定位页面点击自己的停留点后，需要手动切换头像才能看到对应的轨迹
3. **点击另一半的停留点：** 从定位页面点击另一半的停留点后，直接就能看到对应的轨迹（因为默认就是另一半）
