# 轨迹播放动态缩放功能实现

## 功能概述

在轨迹播放过程中，根据当前播放位置周围轨迹点的分布密度，自动调整地图的缩放级别，以便在轨迹密集区域（如终点附近）能够清晰地看到详细的轨迹路径。

## 问题背景

**原问题：**  
用户反馈：轨迹页面播放轨迹动画时，如果起点到终点很远，在终点附近有很多密集的轨迹点，播放时缩放层级一直不变，导致看不清终点附近的轨迹播放细节。

**核心需求：**  
- 在播放长距离轨迹时，起点附近可能比较稀疏，适合用较小的缩放级别
- 在终点附近如果轨迹密集，需要自动放大地图以显示详细路径
- 缩放变化应平滑过渡，避免突兀的视觉体验

## 实现方案

### 1. 核心方法

#### `_calculateOptimalZoomForPosition()`
根据当前位置周围的轨迹点分布计算最佳缩放级别。

**算法逻辑：**
1. **分析范围：** 以当前播放位置为中心，向前和向后各取50个轨迹点（总共约100个点）
2. **计算边界：** 计算这100个点的地理范围（经纬度边界）
3. **计算密度：** 计算这段轨迹的总距离和点密度（每公里点数）
4. **确定缩放：**
   - 首先根据地理范围确定基础缩放级别（范围越小，缩放越大）
   - 然后根据点密度进行微调（密度越高，缩放越大）

**缩放级别映射：**
```dart
// 基于地理范围的缩放级别
maxRange < 0.0005  => zoom = 19.0  // < 50米
maxRange < 0.001   => zoom = 18.5  // < 100米
maxRange < 0.002   => zoom = 18.0  // < 200米
maxRange < 0.005   => zoom = 17.0  // < 500米
maxRange < 0.01    => zoom = 16.0  // < 1公里
maxRange < 0.02    => zoom = 15.0  // < 2公里
maxRange < 0.05    => zoom = 14.0  // < 5公里
maxRange < 0.1     => zoom = 13.0  // < 10公里
maxRange >= 0.1    => zoom = 12.0  // > 10公里

// 基于点密度的微调
densityPerKm > 500  => zoom += 0.5  // 超高密度
densityPerKm > 200  => zoom += 0.3  // 高密度
densityPerKm < 20   => zoom -= 0.3  // 低密度
```

#### `_smoothZoomTransition()`
平滑缩放过渡，避免缩放变化过于剧烈。

**特性：**
- 限制每次缩放变化的最大幅度为 0.5 级
- 记录上一次的缩放级别，逐步调整到目标缩放
- 避免用户感觉到突然的视角跳跃

#### `_moveMapToLocationWithDynamicZoom()`
带动态缩放的地图移动方法。

**特性：**
- 同时更新地图位置和缩放级别
- 使用 `CameraUpdate.newCameraPosition()` 一次性设置位置和缩放
- 包含降级方案：如果出错，退化到只移动位置不调整缩放

#### `_initializeDynamicZoom()`
初始化动态缩放系统。

**时机：** 在开始播放时调用  
**作用：** 获取当前地图的缩放级别，作为平滑过渡的基准

### 2. 性能优化

1. **降低更新频率：**
   - 地图位置和缩放每100毫秒更新一次（在 `_onReplayAnimationUpdate()` 中）
   - 日志输出每20次记录一次，避免日志泛滥

2. **优化索引查找：**
   - 传递 `currentIndex` 参数，避免重复查找最近轨迹点
   - `_findNearestTrackPointIndex()` 只搜索当前位置附近 ±20 个点

3. **缩放范围限制：**
   - 最小缩放级别：12.0（适合超大范围）
   - 最大缩放级别：19.0（适合极小范围）

## 使用效果

### 场景示例

**场景1：长距离轨迹（起点到终点10公里）**
- 起点附近：轨迹稀疏，自动使用较小缩放（zoom ≈ 13-14），可以看到较大范围
- 行进中途：根据轨迹密度动态调整
- 终点附近：轨迹密集（多次往返），自动放大（zoom ≈ 17-18），清晰显示详细路径

**场景2：短距离密集轨迹（终点附近反复移动）**
- 自动检测到高密度区域
- 使用较大缩放级别（zoom ≈ 18-19）
- 用户可以清楚看到每一段轨迹的详细走向

**场景3：均匀分布的轨迹**
- 保持相对稳定的缩放级别
- 只在明显的密度变化处进行调整
- 平滑过渡，不会频繁跳跃

## 技术细节

### 地理计算
- 经纬度差值 0.001 ≈ 111 米（在赤道附近）
- 使用 Haversine 公式计算两点间精确距离

### 缩放平滑策略
- 每次最大变化 0.5 级，避免突然跳跃
- 即使目标缩放从 12.0 变为 18.0，也会分多次逐步调整

### 兼容性
- 包含降级方案：如果动态缩放失败，仍能正常播放（只是不调整缩放）
- 所有地图操作都有错误捕获和日志记录

## 测试建议

1. **长距离轨迹测试：**
   - 选择起点到终点超过5公里的轨迹
   - 观察在不同区域的缩放变化

2. **密集轨迹测试：**
   - 选择在某个区域反复移动的轨迹
   - 验证是否自动放大显示详情

3. **性能测试：**
   - 使用包含1000+轨迹点的数据
   - 观察播放流畅度和CPU使用

4. **边界情况测试：**
   - 轨迹点数很少（<10个）
   - 轨迹点在极小范围内（<50米）
   - 轨迹点分布极不均匀

## 未来优化方向

3. **智能预测：** 提前预测轨迹密度变化，更早开始调整缩放
4. **转弯检测：** 在转弯处自动放大，直线处保持较小缩放
